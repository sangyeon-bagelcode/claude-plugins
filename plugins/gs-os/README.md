# gs-os

슬롯 게임 온톨로지 CLI 사용 스킬. 게임 검색, 태그 조회, 유사 게임 비교 등이 필요할 때 자동 트리거.

## 설치

gs-plugins marketplace에 포함되어 있습니다. marketplace가 설치되어 있다면 자동으로 사용 가능합니다.

## 트리거 조건

슬롯 게임 데이터, 태그, 온톨로지가 필요한 상황에서 자동 트리거:
- "게임 찾아줘", "태그 검색", "유사한 게임"
- "온톨로지", "포트폴리오 통계", "슬롯 분석"
- 특정 태그 이름 언급 (free_spin, way_pay, jackpot 등)
- 게임 ID로 조회, 두 게임 비교

## 선행 조건

gs-os CLI가 설치되어 있어야 합니다. 미설치 시 `/gs-connect`로 설치.
